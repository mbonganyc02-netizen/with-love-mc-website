# With Love MC

Website estático em português para a With Love MC: bolos personalizados, pastelaria e decoração.

## Conteúdo

- `index.html` — estrutura e textos
- `styles.css` — apresentação e versão móvel
- `script.js` — mensagem de pedido via WhatsApp
- `assets/` — logótipo e fotografias

Para pré-visualizar, abra `index.html` no navegador. Os pedidos abrem uma mensagem no WhatsApp; não existe base de dados nem sistema de pagamentos.

## Publicar no GitHub Pages

Em **Settings → Pages**, escolha **Deploy from a branch**, `main` e `/(root)`. O ficheiro `.nojekyll` mantém a publicação dos ficheiros estáticos sem processamento adicional.
